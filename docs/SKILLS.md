# المهارات المطلوبة / Skills you need

Claude Code يكتب الكود. أنت تحتاج تفهم كفاية عشان تقود وتتأكد من النتيجة.

## لازم (أساسي)
| المهارة | ليش | المستوى المطلوب |
|---|---|---|
| Claude Code workflow | `CLAUDE.md`، `/clear` بين المراحل، مراجعة التغييرات قبل القبول | أساسي، ساعة تعلّم |
| تشغيل Python scripts | تشغّل السكربتات وتقرأ الأخطاء | تثبيت venv + `python script.py` |
| أساسيات GIS | CRS والإسقاط وraster و DEM. **أغلب الأخطاء تجي من هنا** | تفهم الفرق بين lon/lat والمتر |
| QGIS (مجاني) | تفتح الـ GeoTIFF وتتأكد بعينك أن الميل منطقي | فتح طبقة + عرض hillshade |
| Git + GitHub Pages | حفظ ونشر الرابط | commit / push / تفعيل Pages |
| التحقق النقدي | تقارن خريطة الصعوبة بالصور: هل الكثبان حمراء؟ | عين + حدس هندسي |

## مفيد (تتعلمه أثناء الشغل)
- JavaScript بسيط (تقرأ الكود وتعدّل ثوابت)
- فكرة A* (يكفي تفهم الفكرة مو الكود)
- تحويل تصميم Canva إلى ألوان وخطوط (CSS variables)

## تجاوزه الآن
3D، PostGIS، FastAPI، Machine Learning، بيانات حية.

## ميزتك كمهندس ميكانيك
معاملات السرعة والطاقة والانزلاق (في `config/params.json`) افتراضات مني. أنت أفضل من يراجعها بفيزياء العجلة والتربة. هذي أقوى نقطة تميّز للمشروع.
